# VocabDNA

Double-click `VocabDNA.bat` on Windows to open the app.

The double-click launcher opens the local static page:

`VocabDNA.html`

The full development server is still available with:

`npm run dev`

Vocabulary data lives in:

- `data/words/*.yaml`
- `data/morphemes/*.yaml`

Adding a new YAML file in either folder automatically adds it to the app index.
